AAB 출시 전 검사기

Play Console에 올리기 전에, 실제로 올라갈 .aab 파일을 열어 흔한 출시 실수를 찾아 줘요.

🔒 파일은 이 기기의 브라우저 안에서만 읽어요. 서버로 보내지 않고, 저장하지도 않아요.

.aab 파일을 여기에 끌어다 놓거나 아래에서 골라 주세요.

Android Studio: Build → Generate Signed App Bundle, 또는 ./gradlew bundleRelease → app/build/outputs/bundle/release/app-release.aab

검사막아 주는 실수
패키지 이름·디버그 빌드.debug가 붙은 디버그 빌드나 다른 앱 파일을 올리는 실수
업로드 키 서명서명 안 된 파일, 디버그 키로 서명한 파일, 다른 업로드 키
versionCode"버전 코드가 이미 사용되었습니다" 오류 (이미 쓴 번호 이하)
광고 ID테스트 트랙에 실제 광고 ID(계정 정지 위험), 정식 출시에 테스트 광고 ID(수익 0원), 다른 앱의 광고 ID
targetSdkPlay가 요구하는 최소 버전보다 낮아 업로드가 거부되는 경우
권한정확한 알람, 위치, SMS처럼 Play Console에 따로 신고해야 하는 권한

검사 방법이 궁금하면 테스트 광고와 실제 광고 구분하기, 버전 코드 이미 사용됨 오류를 읽어 보세요.
