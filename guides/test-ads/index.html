테스트 광고 ID와 실제 광고 ID 구분하기

마지막 확인: 2026년 10월

AdMob을 쓰는 앱에서 가장 위험한 실수는 두 가지예요.

  • 테스트 중인 앱에 실제 광고 ID가 들어감 → 나나 테스터가 광고를 누르면 "무효 클릭"으로 보여 AdMob 계정이 제한되거나 정지될 수 있어요.
  • 정식 출시 앱에 테스트 광고 ID가 남음 → 광고는 "Test Ad"로만 나오고 수익이 0원이에요.

구글 공식 테스트 ID

종류테스트 ID
앱 IDca-app-pub-3940256099942544~3347511713
적응형 배너ca-app-pub-3940256099942544/9214589741
고정 배너ca-app-pub-3940256099942544/6300978111

게시자 번호가 3940256099942544이면 구글 테스트 ID예요. 내 실제 ID는 AdMob > 앱 > 광고 단위에서 확인하고, 앱 ID는 ~, 광고 단위 ID는 /로 나뉘어요. 둘을 바꿔 넣는 실수도 자주 나요.

빌드 종류별로 자동으로 나누기

// app/build.gradle (Groovy)
def TEST_APP_ID = "ca-app-pub-3940256099942544~3347511713"
def TEST_BANNER = "ca-app-pub-3940256099942544/9214589741"
buildTypes {
    debug {
        manifestPlaceholders += [admobAppId: TEST_APP_ID]
        buildConfigField "String", "BANNER_ID", "\"${TEST_BANNER}\""
    }
    release {
        manifestPlaceholders += [admobAppId: providers.gradleProperty("ADMOB_APP_ID").getOrElse(TEST_APP_ID)]
        buildConfigField "String", "BANNER_ID", "\"${providers.gradleProperty("ADMOB_BANNER_ID").getOrElse(TEST_BANNER)}\""
    }
}

매니페스트에는 <meta-data android:name="com.google.android.gms.ads.APPLICATION_ID" android:value="${admobAppId}"/>를 두세요. 비공개 테스트용 릴리스 빌드에도 테스트 ID를 쓰고 싶다면, 테스트 트랙 빌드에서만 -PADMOB_APP_ID=테스트ID로 덮어쓰면 돼요.

비공개 테스트 기간에는 테스트 광고로 충분해요

스토어에 정식 출시되지 않은 앱은 AdMob에서 스토어와 연결할 수 없어서, 실제 광고 수익을 제대로 받기 어려워요. 비공개 테스트 기간에는 테스트 광고로 화면 배치만 확인하고, 프로덕션 승인 뒤 실제 ID로 새로 빌드하세요. 실제 광고를 쓰는 빌드를 내 폰에서 확인해야 한다면 AdMob에 테스트 기기를 등록하세요.

출시 직전에 확인하기

AAB 검사기에 파일을 넣고 올릴 트랙(테스트/프로덕션)을 고르면, 파일 안에 들어 있는 광고 ID가 테스트용인지 실제용인지 찾아서 알려 줘요. 소스 코드가 아니라 최종 파일을 보기 때문에, 빌드 설정이 어떻게 섞였든 정확해요.
